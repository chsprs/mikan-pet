# Mikan Pet v0.1.15

Pembaruan animasi dan distribusi khusus Windows 10/11 x64.

## Animasi dan interaksi

- Tambah 12 pose: membersihkan wajah, meregang, menggaruk telinga, mengibas ekor/telinga, melihat kursor, melompat, mengangguk saat media diputar, menguap, duduk melihat sekitar, bermain bola benang, diangkat, dan mendarat.
- Pet menggantung dengan kaki rileks ketika digeser, bergoyang sesuai arah gerakan, lalu mendarat dan melanjutkan aktivitas sebelumnya.
- Perhalus lompatan, pendaratan, pergerakan bola benang, serta tempo setiap gerakan. Gerakan kecil kursor tidak membuat badan bergetar.
- Pertahankan bentuk kepala, palet empat skin, dan sambungan tubuh pada seluruh frame tambahan.
- Tambahkan pratinjau animasi dari source dengan pilihan skin, arah, dan kontrol per frame.

## Distribusi dan pembaruan

- Satu paket: MikanPet-Setup-x64.exe, khusus Windows 10/11 x64.
- Hapus dukungan build ARM dan paket portable dari jalur distribusi aktif.
- Perbarui dokumentasi serta verifikasi arsitektur installer.
- Skrip rilis mengikuti workflow untuk commit/tag yang tepat dan menjaga encoding UTF-8 file versi.

## Instalasi

Unduh MikanPet-Setup-x64.exe atau gunakan menu Periksa Pembaruan dari aplikasi. Rilis ini unsigned karena sertifikat Authenticode belum dikonfigurasi; Windows dapat menampilkan Unknown publisher.
